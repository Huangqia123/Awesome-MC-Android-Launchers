# Awesome MC Android Launchers

A curated collection of Minecraft Java Edition launchers for Android devices. Discover the best launchers to run Java Edition on your phone or tablet!

| Launcher Name | Description / Features | Best For | Download |
| :--- | :--- | :--- | :--- |
| **Fold Craft Launcher (FCL)** | Specially optimized for CN players. User-friendly UI, built-in Java, easy modpack import. | **Beginners**<br>Looking for stability & ease of use | [GitHub Release](https://github.com/FCL-Team/FoldCraftLauncher/releases) |
| **Zalith Launcher 2 (ZL2)** | Next-gen launcher based on Pojav, rewritten in Kotlin. Great performance and frequent updates. | **Advanced Users**<br>Chasing performance & new features | [GitHub Release](https://github.com/ZalithLauncher/ZalithLauncher2/releases) |
| **Amethyst** | An active open-source project, serves as a lightweight alternative to Pojav. | **Power Users**<br>Need lightweight or self-debugging | [GitHub Release](https://github.com/AngelAuraMC/Amethyst-Android/releases) |
| **PojavLauncher** | Classic and highly compatible. **(Note: Archived in Sep 2025. The team moved to Amethyst. New players should choose others above.)** | **Nostalgia / Testing**<br>Only for testing old version compatibility | [GitHub Release (Archived)](https://github.com/PojavLauncherTeam/PojavLauncher/releases) |
